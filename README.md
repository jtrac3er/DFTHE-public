# FHE Research

## Failed attempts

The versions v1 until v9 include candidate constructions which I have tested over over the course of about 2 years. For all of them I was able to find concrete 
counterexamples. They all explore different ideas, where complex numbers over a finite field, quaternions over a finite field and more on were used
in order to achieve a scheme, but like mentionned, they all were proven insecure by a counterexample. 

## DLog Index

This theoretical construction includes a new idea for achieving FHE, which was also proven to be insecure by myself. 

## Group rings

Group Rings are a construction which include all my previous approaches. They all can be viewed as instances of group rings. I began to research
group rings in detail and checking them for feasability for FHE constructions. So far, the folder only contains certain tests for number theory 
and a paper which slightly touches an idea for a construction. The paper is only a draft and contains many assumptions which were not proved, but it
should show the general idea.
